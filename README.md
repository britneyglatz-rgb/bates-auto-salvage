# Bates Auto Salvage — Yard Desk App

Simple storefront + office desk for Bates Auto Salvage.

## What it does

- **Yard inventory** with year / make / model search
- **Easy product upload** (photos, price, yard row, condition)
- **Customer part requests**n- **Office chat inbox** (website chat + per-request threads)
- **Yard settings** (name, phone, address, hours)

## How to open

No install. Open `index.html` in Chrome or Edge.

```bash
python3 -m http.server 8080
```

Visit http://localhost:8080
